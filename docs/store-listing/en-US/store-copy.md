## Full description

SafeSpeak is an accessibility-focused livestream companion that reviews text
before it is spoken aloud.

The current mobile test application provides an offline test lab for SafeSpeak’s
portable moderation and your phone or tablet’s built-in text-to-speech service.
Enter a message, review it, explicitly arm speech, and then choose whether to
hear the approved result. Mobile test builds do not currently connect to a live
platform account.

SafeSpeak is designed around predictable control:

- Speech starts disarmed.
- Messages are reviewed before speech.
- Stop speech is always available from the test screen.
- Current processing occurs on your device.
- No SafeSpeak account, advertising, tracking, or developer analytics are included.
- Screen-reader context, large touch targets, clear written states, and scalable
  layouts are core requirements.

Automated moderation can make mistakes and cannot guarantee that every harmful
message will be detected. Keep the livestream platform’s moderation tools and
trusted human moderators active.

SafeSpeak’s Windows application is the primary release target. Android and iOS
versions are under active development, and available features may differ.
