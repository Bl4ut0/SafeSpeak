# Store reviewer notes

SafeSpeak starts disarmed and does not speak text automatically.

To review the current mobile test build:

1. Launch SafeSpeak.
2. Leave the safety switch off and select **Review test message**. The text is
   moderated but not spoken.
3. Turn on **Allow approved test messages to speak**.
4. Select **Speak approved message** to use the device text-to-speech service.
5. Select **Stop speech** to cancel speech.

No account or external hardware is required. The current mobile build does not
authenticate with TikTok, TikFinity, YouTube, Twitch, or another livestream
platform. Connector names shown in the application are development-status
information, not claims of live integration.

The application does not contain advertising, tracking, developer analytics, or
telemetry. The Project Hub does not receive the text entered into the test screen.
