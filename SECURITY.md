# Security policy

SafeSpeak processes hostile livestream chat and should be treated as security-sensitive software.

## Development status

There is no supported release yet. The repository is an early foundation and must not be relied on as the only protection for a live broadcast.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** option on the repository's Security tab when it is available. Do not post exploit payloads, bypass terms, personal information, or unsafe chat samples in a public issue.

Include the SafeSpeak version or commit, Windows and TikFinity versions, whether Stream Deck was running, a minimal redacted reproduction, and the observed versus expected safe behavior. Never include livestream credentials or unredacted chat logs.
